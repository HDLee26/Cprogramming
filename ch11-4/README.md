# 실습과제 1
- B, 'B', "B" 의 차이를 설명하라
  - B : 식별자. 변수명이나 상수명 등.
  - 'B' : 문자 상수. 단일 문자 하나. 보통 char형 변수에 저장하고 1바이트 차지. 서식지정자 %c.\
    다만 C의 문자 상수 타입은 int임. 문자를 저장할 때 정수로 바꾸어 저장하기 때문에.
  - "B" : 문자열 리터럴. 끝에 자동으로 '\0' 포함되어 2바이트 차지. 서식지정자 %s.
