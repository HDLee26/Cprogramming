# 실습과제 1
- 배열명의 의미를 설명하라\
배열의 첫번째 원소의 주소 &arr[0]을 의미함.
- 배열 표현과 포인터(주소) 표현의 변환 공식을 설명하라\
  a[i] = *(a + i)\
  배열명을 포인터처럼 이용하여 주소와 값을 구하는 것이 가능하다.
- 배열의 첫 번째 요소의 주소만 알면 모든 원소의 주소를 계산할 수 있다. 방법을 설명하라.\
  임의의 배열명 arr이 있다고 할 때, 첫 번째 원소의 주소가 &arr[0]이므로 &arr[1], &arr[2] ... 인덕스 번호만 키우면 된다. 혹은 첫 번째 원소의 주소를 포인터 변수 ptr에 저장한다고 한다면, ptr + 0, ptr + 1, ptr +2 ...처럼 하면 된다.
- 배열의 첫번째 요소의 주소만 알면 모든 원소의 값을 계산할 수 있다. 방법을 설명하시오.\
  임의의 배열명 arr이 있다고 할 때, 첫 번째 원소의 값은 arr[0]이므로 arr[1], arr[2] ... 인덱스 번호만 키우면 된다. 혹은 첫 번째 원소의 주소를 포인터 변수 ptr에 저장한다고 한다면, *(ptr + 0), *(ptr + 1), *(ptr + 2) ... 처럼 간접참조연산자를 이용한다.
- 포인터에 대해 가능한 연산의 종류와 의미를 설명하라.\
간접참조 연산자(\*) : 포인터에 저장된 주소로부터 포인터가 가리키는 자료형의 크기만큼 읽거나 씀.
정수(n)가감 연산 : ±n×(포인터가 가리키는 자료형의 크기)만큼 주소 이동
증감 연산 : ±1×(포인터가 가리키는 자료형의 크기)만큼 주소 이동
