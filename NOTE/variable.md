# 지역변수 (local variable)
```c
for ( ; ; )
    {
        // 실행
    }

if ( )
{
    // 실행
}

void func(void)
{
    // 실행
}
```
- C에서 local이란 중괄호 한 블럭 한 블럭을 말함. 중괄호 안에 선언되는 변수들을 지역변수라고 한다.
  중괄호 안에 선언되는 거니까 함수, 반복문, 조건문 다 포함.
- 지역변수는 선언된 지역 내에서만 접근 가능하다. 해당 지역을 벗어나면 지역변수는 메모리에서 소멸되며, 호출 때마다 새로 할당된다.
- 따라서 다른 지역에 동일한 이름의 지역변수를 선언하는 것이 가능하다. 이때 지역변수는 각 지역 내에서만 접근 가능하므로
  이름이 같다고 값을 덮어쓰지 않는다. 함수, 반복문, 조건문 내의 지역변수가 외부의 동일한 이름의 변수보다 우선된다.
- 서로 동일한 이름의 전역변수와 지역변수를 만들어 쓰는 경우에도 해당하는 영역의 지역변수는 전역변수보다 우선된다.
- 반복문에 의한 반복은 중괄호의 진입과 탈출을 반복하면서 이루어지는 것이다.
  따라서 반복문 안의 지역변수도 반복이 이뤄질 때마다 할당되고 소멸된다.
- C의 메모리구조에 대하여 더 공부해야 함. // 26.10.10

# 스태틱 변수 (static)
- static 지역변수는
  - 프로그램 시작과 동시에 할당 및 초기화되며 프로그램 종료시까지 메모리 공간에 남아있는다. (전역변수 특성)
  - 하지만 선언된 지역 내에서만 접근 가능하다. (지역변수 특성)
- 가능하다면 전역변수보단 static 지역변수를 쓰는 것이 안전하다.
```c
#include <stdio.h>

void func(void)
{
    static int num1;    // 스태틱 변수는 초기화하지 않아도 0으로 초기화됨.
    int num2 = 0;       // 일반 지역변수는 초기화하지 않으면 쓰레기값.
    num1++, num2++;
    printf("static: %d, local: %d\n", num1, num2);
}

int main(void)
{
    int i;
    for(i = 0; i < 3; i++)
    {
        func();
    }
    return 0;
}
```
- num2는 func()의 지역변수로 호출될 때마다 새로 초기화되어 결과가 모두 1임.
- num1도 지역변수이지만 static으로 선언되었으므로 처음 0으로 초기화된 후에는 초기화되지 않는다. (메모리에서 소멸되지 않음.) 그래서 값이 계속 보존되어 최종결과가 3이다.
